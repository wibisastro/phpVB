**Release Date:** 8 Oktober 2026
**Referensi:** phpVB/rencana/phpvb-manifest-mcp-run.md (generator gov3phpvb `phpvb_manifest`, MCP generik `phpvb-run`)

## ✨ Fitur

### `Gov2lib\manifest` — portal menerbitkan kontrak API-nya sendiri

Setiap app hasil vibe coding (gov3phpvb) membawa tiga dokumen Markdown; framework menyajikannya lewat satu
rute inti sehingga **agen** (MCP, pembangun MCP) tahu cara memanggil setiap fn controller tanpa membaca source,
dan **manusia** membacanya di browser dengan tata letak app.

| Berkas di app | Isi | Rute |
|---|---|---|
| `view/manifest.md` | kontrak API: transport, auth, per MVC: cmd + URL + argumen wajib/opsional + balasan + alur (tambah/ubah/hapus — hapus lewat `edit/{id}` dulu = konfirmasi), field form, **blok data JSON** per MVC | `GET /{app}/manifest` · `/raw` · `/mvc/{nama}` |
| `view/release.md` | kronologis versi app (terbaru di atas, `## v1.2.0 — tanggal`) | `GET /{app}/manifest/release[/raw]` |
| `README.md` | konteks domain app & tiap MVC | `GET /{app}/manifest/readme[/raw]` |

Bentuk balasan mengikuti `Accept`: HTML (browser, template `core/template/general/manifest.html`, blok data
disembunyikan), JSON bila `Accept: application/json` (`{ok, app, versi, skema, berkas, url, mvc (ringkas),
data (blok JSON per MVC), galat (hasil validasi pengurai), markdown}`), atau `text/markdown` mentah lewat `/raw`.
`GET /{app}/manifest/ping` (tanpa login) melaporkan ada/tidaknya tiga berkas + versi.

Pengurai `Gov2lib\Manifest\Parser` (logika murni): blok bertanda `<!-- manifest:mvc:{nama} start/end -->`
milik generator (diganti utuh saat regenerasi), fence ```` ```json manifest ```` (per MVC) dan
```` ```json manifest-app ````; galat dilaporkan bernama (`MVC x: cmd add method harus GET/POST`), tidak dilempar.
Fixture `tests/fixture/manifest/bukutamu.md` dipakai bersama generator Python dan MCP phpvb-run.

**Akses & keamanan:** `authenticate('guest')` — harus login (STAGE `local` terbuka seperti halaman lain);
app boleh membuka untuk publik dengan `<manifest>public</manifest>` di `apps/{app}/xml/config.xml`.
Isinya berkas statis yang ditulis generator/pengembang: tidak ada DB, tidak ada rahasia. Tanpa berkas →
404 `ManifestNotFound` (halaman: pemberitahuan cara membangkitkan). Nama `manifest` kini **terlarang**
sebagai nama MVC app (bentrok rute inti) — generator gov3phpvb menolaknya (J05).

**Keputusan sadar:** manifest statis (berkas), bukan refleksi runtime atas class controller — refleksi tidak
tahu argumen wajib/alur, berkas bisa di-review & di-commit bersama kode, dan tidak ada biaya saat request.
Yang menjaga manifest tetap sinkron dengan controller adalah validator gov3phpvb (`phpvb_periksa` J34–J36),
bukan framework.

## 🧩 Berkas

- `core/lib/manifest.php` (controller), `core/lib/manifestHandler.php` (model: lokasi & pembacaan tiga berkas),
  `core/lib/Manifest/Parser.php` (pengurai), `core/template/general/manifest.html` (halaman).
- `core/config/route.xml` (+2 rute `GET /{app}/manifest`, `/{app}/manifest/{cmd}[/{id}]`), `core/init/route.php`
  (case `manifestHandler` → `Gov2lib\manifest`).
- Uji: `tests/Unit/Lib/ManifestParserTest.php` (7), `tests/Unit/Lib/ManifestTest.php` (9) — 100 asersi; fixture
  `tests/fixture/manifest/bukutamu.md`.

## 🚀 Pemasangan

Tidak ada konfigurasi server: `git pull` lalu `GET /{app}/manifest/ping`. Endpoint hanya berisi sesuatu bila app
punya `view/manifest.md` (dibangkitkan `phpvb_manifest` gov3phpvb, atau ditulis tangan mengikuti fixture).
