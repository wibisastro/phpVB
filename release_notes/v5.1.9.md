# v5.1.9 — Artefak MVC berakar `artefak` (segmen URL berbahasa Indonesia)

**Release Date:** 9 Oktober 2026
**Referensi:** phpVB/rencana/sdd-berbasis-tiket.md (arahan 9 Okt: "nama root-nya artefak/ (isinya readme), artefak/manifes,
artefak/rilis, artefak/berkas (raw)"; spec tetap ada sebagai `artefak/spek` = salinan beku spec dari tiket)

---

## 🔄 Perubahan dari v5.1.8

Akar dokumen MVC kini **`artefak`**; sub-segmennya berbahasa Indonesia. **Nama berkas tidak berubah.**

| Endpoint v5.1.9 | Berkas | Isi | Alias v5.1.8 (deprecated) |
|---|---|---|---|
| `GET /{app}/{mvc}/artefak` | `view/{mvc}/readme.md` | konteks domain MVC (akar) | `…/readme` |
| `GET /{app}/{mvc}/artefak/manifes` | `view/{mvc}/manifest.md` | kontrak API MVC — agen/MCP (phpvb-run) | `…/readme/manifest` |
| `GET /{app}/{mvc}/artefak/rilis` | `view/{mvc}/release.md` | kronologis versi MVC | `…/readme/release` |
| `GET /{app}/{mvc}/artefak/spek` | `view/{mvc}/spec.md` | prompt spesifikasi (salinan beku spec tiket) | `…/readme/spec` |
| `…/berkas` (mis. `/artefak/berkas`, `/artefak/spek/berkas`) | — | `text/markdown` mentah — salin = salin berkas | `…/raw` |
| `POST /{app}/{mvc} {"cmd":"artefak","jenis":"spek","format":"berkas"}` | — | setara | `cmd=readme, jenis=spec, format=raw` |
| `GET /{app}/artefak` (+ `/ping`) | — (dihitung) | indeks MVC bermanifest (judul "Artefak — {app}") | `/{app}/readme`, `/{app}/manifest` |

Kunci peta `url` di balasan JSON tetap bahasa Inggris (`readme`, `manifest`, `release`, `spec`, `raw`, `indeks_app`) karena itu
kontrak yang dibaca phpvb-run; nilainya memakai segmen baru.

## ♻️ Kompatibilitas

- cmd `readme` (v5.1.8) dan `manifest` (v5.1.7) tetap dilayani sebagai alias; segmen lama (`manifest`, `release`, `spec`, `raw`)
  diterima juga di bawah cmd `artefak` (`Endpoint::SEGMEN`). MCP phpvb-run gov3phpvb memakai URL baru dan jatuh ke alias.
- `artefak` menjadi nama MVC terlarang (J05) bersama `readme`, `manifest`, `agendb`, `agen`. Controller yang punya method
  `artefak()` sendiri tetap menang (dispatcher memeriksa method controller lebih dulu).

## 🧩 Berkas

- `core/lib/Manifest/Endpoint.php` — `CMD = 'artefak'`, `CMD_LAMA = ['readme','manifest']`, `CMDS`, `SEGMEN`/`SEGMEN_JENIS`, `url()` baru, judul akar `Artefak — {app}/{mvc}`
- `core/init/index.php` (komentar), `core/init/route.php` (komentar)
- `core/lib/manifest.php`, `manifestHandler.php`, `core/config/route.xml` — indeks `/{app}/artefak[/{cmd}]` (+ alias `/readme`, `/manifest`)
- `core/template/general/manifest.html` — komentar
- `tests/Unit/Lib/ManifestTest.php` (+ fixture `tests/fixture/manifest/bukutamu/view/*/*.md` dimigrasi ke URL baru, identik dengan gov3phpvb)
