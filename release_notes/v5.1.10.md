# v5.1.10 — Tema tampilan per app (`apps/{app}/xml/tema.xml`)

**Release Date:** 14 Oktober 2026
**Referensi:** phpVB/rencana/sdd-berbasis-tiket.md §6 (arahan Wibi 14 Okt: "bisa beda tema template kalo beda aplikasi walau masih
dalam satu framework portal"); bootstrap `rencana/pabrik-tema.md` + skill `phpvb-bootstrap` (tema admin overlay vs halaman publik).

---

## 🔄 Perubahan dari v5.1.9

Tema admin (overlay `cube*` di `core/template/{tema}`, mis. `gelap`) dulu hanya bisa dipilih **per portal** lewat `<template>` di
`core/config/config.{stage}.xml`, sehingga semua app di satu portal berkulit sama. Kini app boleh menetapkan temanya sendiri.

| Tingkat | Sumber | Keterangan |
|---|---|---|
| 1 | `apps/{app}/xml/tema.xml` → `<tema>gelap</tema>` | per app; `cube` eksplisit = tetap cube walau portal memakai tema lain |
| 2 | `<template>` config portal | bawaan untuk app yang tidak menetapkan tema sendiri (perilaku v5.1.9, tidak berubah) |
| 3 | `cube` | tanpa keduanya, nama tak valid (`^[a-z0-9_-]+$`), atau folder tidak ada |

- Kelas baru `Gov2lib\Tema` (`pilih`, `bacaApp`, `valid`) — murni, diuji `tests/Unit/Lib/TemaTest.php`.
- `core/init/template.php` memakai `Tema::pilih(core/template, $config->template, dirname($self->templateDir))`; urutan pencarian
  Twig tanpa namespace tetap `[tema?, cube, general]`, namespace `@{tema}` per folder tetap ada (tema halaman publik tidak lewat
  mekanisme ini — app meng-extend `@{tema}/layout.html`).
- Variabel Twig baru `tema` (nama tema aktif) di body dokumen.

Contoh `apps/disposisi/xml/tema.xml`:

```xml
<?xml version="1.0" encoding="UTF-8"?>
<!-- Tema tampilan app ini: nama folder core/template/{tema} (phpvb_tema). Mengalahkan <template> config portal. -->
<tema>gelap</tema>
```

## Kompatibilitas

Tanpa `xml/tema.xml` tidak ada yang berubah: app mengikuti `<template>` portal seperti sebelumnya. Nama yang tidak valid atau
folder yang tidak ada diabaikan (jatuh ke portal → cube), bukan galat.

## gov3phpvb

`phpvb_app_baru spesifikasi.tema=<nama>` (tema admin) menulis `xml/tema.xml`; validator J39 memeriksa nama tema terhadap
`knowledge/tema.json`; konsultasi menawarkan daftar tema (`phpvb_tema`) dan tiket induk app mencatatnya di bagian 10.
