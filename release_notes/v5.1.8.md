# v5.1.8 — Dokumen MVC berakar `readme` + dokumen keempat `spec`

**Release Date:** 8 Oktober 2026
**Referensi:** phpVB/rencana/phpvb-readme-spec-mvc.md (arahan 8 Okt: "root-nya readme, sub-nya readme/manifest, readme/release,
readme/raw dan readme/spec — spec isinya prompt tentang spec yang menghasilkan MVC tersebut, jadi jika ingin meng-copy spec-nya
tinggal copy file itu")

---

## 🔄 Perubahan dari v5.1.7

Akar dokumen MVC kini **`readme`** (konteks untuk manusia), kontrak API pindah ke sub `manifest`, dan ada dokumen keempat **`spec`**:

| Endpoint | Berkas | Isi |
|---|---|---|
| `GET /{app}/{mvc}/readme` | `apps/{app}/view/{mvc}/readme.md` | konteks domain MVC (akar) |
| `GET /{app}/{mvc}/readme/manifest` | `view/{mvc}/manifest.md` | kontrak API MVC — untuk agen/MCP (phpvb-run) |
| `GET /{app}/{mvc}/readme/release` | `view/{mvc}/release.md` | kronologis versi MVC |
| `GET /{app}/{mvc}/readme/spec` | `view/{mvc}/spec.md` | **baru** — prompt spesifikasi (bahasa pengguna) yang menghasilkan MVC ini |
| `…/raw` (mis. `/readme/raw`, `/readme/spec/raw`) | — | `text/markdown` mentah — `/readme/spec/raw` = isi berkas spec, siap disalin |
| `POST /{app}/{mvc} {"cmd":"readme","jenis":"spec","format":"raw"}` | — | setara |
| `GET /{app}/readme` (+ `/ping`) | — (dihitung) | indeks MVC bermanifest; tabel kini menautkan readme, manifest, dan spec |

`spec.md` dibangkitkan gov3phpvb (`phpvb_bangun`, `phpvb_app_baru`, `phpvb_tambah_fitur`, `phpvb_manifest spec=…`): baris komentar
`<!-- spec phpVB: … -->`, kata-kata asli pengguna, blok `<!-- spec:rincian -->` (bentuk halaman, isian, fitur, hak akses — milik
generator), catatan tambahan. Komentar HTML dibuang saat dirender (`html_input: strip`), jadi tidak tampil di halaman.

## ♻️ Kompatibilitas

- **Alias v5.1.7 tetap dilayani (deprecated):** `/{app}/{mvc}/manifest[/readme|/release|/spec][/raw]` (akarnya manifest) dan
  `/{app}/manifest[/ping]`. MCP phpvb-run gov3phpvb memakai URL baru dan jatuh ke alias bila portal masih 5.1.7.
- Berkas tidak berpindah: `view/{mvc}/{readme,manifest,release}.md` sama seperti v5.1.7; cukup tambah `spec.md`.
- `readme` menjadi nama MVC terlarang (J05) bersama `manifest`, `agendb`, `agen`. Controller yang punya method `readme()` sendiri tetap
  menang (dispatcher memeriksa method controller lebih dulu).

## 🧩 Berkas

- `core/lib/Manifest/Endpoint.php` — `CMD = 'readme'`, `CMD_LAMA = 'manifest'`, `CMDS`, jenis `spec`, `url()` baru, judul `Spec — {app}/{mvc}`
- `core/init/index.php` — dispatcher: `in_array($cmd, Endpoint::CMDS, true)`
- `core/lib/manifest.php`, `manifestHandler.php`, `core/config/route.xml` — indeks `/{app}/readme[/{cmd}]` (+ alias `/{app}/manifest`)
- `core/template/general/manifest.html` — komentar
- `tests/Unit/Lib/ManifestTest.php` (+ fixture `tests/fixture/manifest/bukutamu/view/*/spec.md`, identik dengan gov3phpvb)
