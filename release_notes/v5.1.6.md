**Release Date:** 8 Oktober 2026
**Referensi:** phpVB/rencana/phpvb-manifest-mcp-run.md §7 (MCP generik `phpvb-run`); generalisasi `agen.php` app sdi-staging (MCP gov3sdi, rencana sdi/gov3sdi-mcp.md §2)

## ✨ Fitur

### `Gov2lib\agen` — pertukaran identitas kancil → sesi portal, sebagai endpoint inti semua app

Agar MCP generik `phpvb-run` bisa menjalankan cmd app apa pun **atas nama pengguna yang login di kancil** (role,
superuser, konteks persis seperti ia membuka portal di browser), tanpa setiap app harus menulis `agen.php` sendiri.

| Rute | Isi |
|---|---|
| `GET /{app}/agen[/ping]` | hidup, rahasia terpasang? (tanpa identitas) |
| `POST /{app}/agen {"cmd":"sesi"[,"ttl"]}` + `X-Phpvb-Agen-Secret`, `X-Gov3-User` (email), `X-Gov3-Session` | `{token (JWT Gov2Session), cookie, exp, ttl, csrf, member, superuser}` |
| `POST /{app}/agen {"cmd":"siapa"}` + `Cookie: Gov2Session=…` | klaim sesi pemanggil + `superuser` app ini + `konteks` (`opd_id`, `opd`, `wilayah_id`, …) — tanpa rahasia, cookie = bukti |

Token = JWT HS256 dengan `$publickey` server, klaim seperti hasil login SSO + `authenticate()` (`account_id`, `fullname`,
`email`, `id`, `userRole`, `status`, `pageID`) + penanda `agen: phpvb` / `agen_session` untuk audit; `csrf` = token
CSRF stateless framework (`core/lib/csrf.php`). Hanya member yang **sudah terdaftar** (pernah login) yang bisa ditukar —
tidak ada pembuatan member.

**Pengaman (fail-closed):** mati tanpa rahasia per server (env `PHPVB_AGEN_SECRET` atau `core/config/agen.secret`,
gitignored — **terpisah** dari `agendb.secret` karena kewenangannya lebih besar: menerbitkan sesi) → 503 `AgenDisabled`;
`hash_equals`; cmd `sesi` hanya POST (405); email wajib valid (`BLOCKED_NO_IDENTITY`); `X-Gov3-Session` wajib
(`SessionRequired` — hanya klien ber-`identity:true`); `NoAccount` 404 / `AmbiguousAccount` 409 / `Suspended` /
`Pending` 403; TTL bawaan 8 jam, maksimum 24 jam; audit satu baris JSON per permintaan ke `error_log` **tanpa token**.
Pencarian member memakai `agendbHandler::cariMember` (DSN `master` app, sesi MySQL READ ONLY).

## 🧩 Berkas

- `core/lib/agen.php` (controller), `core/lib/agenHandler.php` (model — mewarisi agendbHandler untuk `cariMember`).
- `core/config/route.xml` (+3 rute `/{app}/agen`), `core/init/route.php` (case `agenHandler` → `Gov2lib\agen`).
- Uji: `tests/Unit/Lib/AgenTest.php` (8 uji, 59 asersi: gerbang, klaim JWT, csrf, TTL, `siapa`, audit tanpa token).

## 🚀 Pemasangan

```sh
cd /var/www/<framework> && git pull --ff-only
umask 077; openssl rand -hex 32 > core/config/agen.secret && chmod 640 core/config/agen.secret && chgrp www-data core/config/agen.secret
curl -s -H 'Accept: application/json' https://<portal>/<app>/agen/ping   # → "secret_configured":true
```

Rahasia yang sama diisi ke `GOV3PHPVB_RUN_AGEN_SECRET` di env MCP `phpvb-run` (kancil). Tanpa berkas rahasia 633 portal
tidak berubah perilaku. App `sdi` yang masih memakai `agen.php` sendiri (`/sdi/agen`, rahasia `xml/agen.secret`) tidak
terpengaruh: `POST /sdi/agen` (statis) memang milik app, dan untuk `GET /sdi/agen/{cmd}` — yang oleh FastRoute diarahkan ke rute
dinamis inti karena terdaftar lebih dulu — `core/init/route.php` mengalihkan ke controller/model app bila `apps/{app}/agen.php`
ada. Migrasi gov3sdi ke endpoint inti menyusul.
