# v5.1.7 — Manifest PER MVC: `/{app}/{mvc}/manifest` (cmd bawaan setiap controller app)

**Release Date:** 8 Oktober 2026
**Referensi:** phpVB/rencana/phpvb-manifest-mcp-run.md (koreksi arahan 8 Okt: "satu MVC punya masing-masing manifestnya …
navigasi hanya berdasarkan endpoint", contoh `https://becik.kukarkab.go.id/sdi/sekretariat/manifest`)

---

## 🔄 Perubahan dari v5.1.5

v5.1.5 menyimpan satu `view/manifest.md` per app (berbagian per MVC) dan menyajikannya di `/{app}/manifest` dengan tombol
navigasi. Sekarang **setiap MVC punya tiga dokumennya sendiri** dan endpoint-nya ada di bawah MVC itu:

| Endpoint | Berkas | Isi |
|---|---|---|
| `GET /{app}/{mvc}/manifest` | `apps/{app}/view/{mvc}/manifest.md` | kontrak API MVC (cmd, argumen, balasan, alur, field + blok `json manifest`) — untuk agen/MCP |
| `GET /{app}/{mvc}/manifest/readme` | `view/{mvc}/readme.md` | konteks domain MVC |
| `GET /{app}/{mvc}/manifest/release` | `view/{mvc}/release.md` | kronologis versi MVC |
| `…/raw` (mis. `/manifest/raw`, `/manifest/readme/raw`) | — | `text/markdown` mentah |
| `POST /{app}/{mvc} {"cmd":"manifest","jenis":"readme","format":"raw"}` | — | setara |
| `GET /{app}/manifest` | — (dihitung) | **indeks**: MVC bermanifest + endpoint + versi; `tanpa_manifest` (JSON untuk agen menemukan MVC) |
| `GET /{app}/manifest/ping` | — | daftar MVC bermanifest / belum (tanpa login) |

Halaman HTML **tanpa tombol** — navigasi lewat endpoint. JSON (`Accept: application/json`): `{ok, app, mvc, jenis, versi, skema,
berkas, url, app_data, data (blok MVC terurai), galat, markdown}`.

## ⚙️ Cara kerja: cmd bawaan, bukan method di kelas dasar

`manifest` ditangani **dispatcher** (`core/init/index.php`): bila controller app (`App\…`) tidak punya method `manifest`, cmd itu
disajikan `Gov2lib\Manifest\Endpoint`. Akibatnya:

- endpoint memakai **rute standar MVC itu sendiri** (`/{app}/{mvc}/{cmd}[/{id}]`, `/{cmd}/{scroll}/[{id}]`, POST) — tidak ada rute baru per MVC;
- **konstruktor controller sudah berjalan** → `authenticate()` MVC berlaku (yang boleh membuka MVC, boleh membaca manifest-nya; MVC
  yang hanya menjaga `index()` (J09) juga terbuka manifest-nya — sama dengan cmd JSON-nya);
- controller yang **sudah** punya method `manifest` tetap menang — tidak ada fatal error kompatibilitas tanda tangan PHP 8.4 seperti bila
  method ditambahkan ke `Gov2lib\api` (jebakan "render() bentrok document"), aman untuk 633 portal;
- berlaku untuk semua app, termasuk MVC tulis tangan (mis. `sdi/sekretariat`) — isi tinggal berkasnya.

## 🧩 Berkas

- `core/lib/Manifest/Endpoint.php` (baru), `core/init/index.php` (cabang cmd `manifest`), `core/lib/manifest.php` +
  `manifestHandler.php` (kini indeks: `index`, `ping`), `core/template/general/manifest.html` (tanpa tombol).
- Fixture per MVC `tests/fixture/manifest/bukutamu/view/{kunjungan,jenis_keperluan}/{manifest,release,readme}.md` (dipakai bersama
  gov3phpvb); `tests/Unit/Lib/ManifestTest.php` (endpoint + indeks, 8 uji). `Manifest\Parser` tidak berubah.

`phpvb_manifest` (gov3phpvb).
