**Release Date:** 8 Oktober 2026

## ✨ Fitur

### `Gov2lib\agendb` — cek hasil CRUD web langsung di DB, tanpa akun DB baru

Kebutuhan: pengembang app (mis. pelatihan vibe coding) sering perlu memastikan data yang disimpan
lewat form web benar-benar masuk ke tabel yang benar dengan nilai yang benar. Sebelumnya butuh akses
MySQL langsung (akun, password, tunnel). Sekarang cukup lewat agen (kancil) yang memanggil endpoint
framework ini; kredensial DB = **entri `dsnSource` app yang sama dengan yang dipakai model app**.

Rute bawaan (`core/config/route.xml`, berlaku semua app):

| Rute | Isi |
|---|---|
| `GET /{app}/agendb[/ping]` | hidup, rahasia terpasang?, entri DSN bawaan (tanpa identitas) |
| `GET /{app}/agendb/dsn` · `/tabel` | entri DSN (tanpa rahasia) · daftar tabel + kolom waktu |
| `POST /{app}/agendb {"cmd":"struktur","tabel"}` | kolom, indeks, DDL, jumlah baris, catatan konvensi phpVB (id AI, kolom audit, J08) |
| `POST … {"cmd":"terbaru","tabel"?,"sejak"?,"batas"?}` | tanpa `tabel`: tabel yang berubah sejak `15m`/`2j`/`1d`/waktu; dengan `tabel`: baris terbaru, `kolom_selalu_kosong`, created_by kosong |
| `POST … {"cmd":"kueri","sql","batas"?}` | satu pernyataan SELECT/WITH/SHOW/DESCRIBE/EXPLAIN yang ditulis agen |

Header: `Accept: application/json`, `X-Phpvb-Agendb-Secret`, `X-Gov3-User` (email; gov3code `identity:true`),
`X-Gov3-Session` (audit). Argumen opsional `dsn` memilih entri lain di dsnSource app (mis. `master`).

**Pengaman (berlapis, dari yang paling menentukan):**
1. **Mati secara bawaan** — tanpa rahasia bersama per server (env `PHPVB_AGENDB_SECRET` atau berkas
   `core/config/agendb.secret`, kini gitignored) → 503 `AgenDbDisabled`. 633 portal tidak berubah perilaku
   setelah pull.
2. **Identitas = pemilik app**: email → member portal (DSN `master`) yang berperan `webmaster`/`developer`
   atau tercantum di `apps/{app}/xml/superuser.xml` (`gov2session::checkSuperuser`). Selain itu
   `BLOCKED_BUKAN_PENGEMBANG`; akun `suspended`/`pending` ditolak.
3. **Sesi MySQL `READ ONLY`** (`SET SESSION TRANSACTION READ ONLY` → DML ditolak MySQL, ER 1792) +
   `max_execution_time`/`max_statement_time` 10 s + `sql_select_limit`; user DSN app memang tanpa DDL.
4. **Penjaga SQL** `Gov2lib\Database\ReadOnlySql`: satu pernyataan; diawali SELECT/WITH/SHOW/DESCRIBE/EXPLAIN;
   tanpa `INTO OUTFILE`, `FOR UPDATE`, `SLEEP()`/`LOAD_FILE()`, komentar `/*! */`; `WITH … DELETE` /
   `EXPLAIN DELETE` ditolak.
5. Kolom bernama rahasia (`password`, `token`, `ssokey`, …) disamarkan; nilai biner ditandai; teks dipotong;
   balasan dipangkas ≤ 60 k karakter. Audit satu baris JSON per panggilan ke `error_log` (email, cmd, dsn,
   tabel, awal sql, hasil, ms — **tanpa isi baris**).

Batasan: hanya driver `meekro` (MySQL); entri `supabase` → 501 `DriverTidakDidukung`.

## 🧩 Berkas

- `core/lib/agendb.php` (controller), `core/lib/agendbHandler.php` (model: DSN, koneksi mysqli baca-saja,

  `AgendbException`).
- `core/config/route.xml` (+3 rute), `core/init/route.php` (case `agendbHandler` → `Gov2lib\agendb`),
  `.gitignore` (`/core/config/*.secret`).
- Uji: `tests/Unit/Lib/ReadOnlySqlTest.php` (penjaga SQL 30 kasus, kolom waktu, SQL bantu, penyamaran,
  catatan konvensi).

## 🚀 Pemasangan di server

```sh
# di host portal, sebagai pemilik checkout framework
umask 077; openssl rand -hex 32 > core/config/agendb.secret   # lalu chown ke user web, mode 640
curl -s -H 'Accept: application/json' https://<portal>/<app>/agendb/ping   # secret_configured: true
```
Nilai yang sama dipasang di sisi MCP gov3phpvb (`GOV3PHPVB_DB_SECRET`). Tanpa berkas ini endpoint tetap 503.
